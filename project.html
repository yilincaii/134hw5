Kaggle Competition: LLM Mathematical Reasoning

Type: Machine Learning and LLM Inference

This project focused on improving the mathematical reasoning performance of Qwen3-4B-Thinking, a four-billion-parameter inference model. We worked under the constraints that we could not fine-tune the model weights or use external tools.

We designed a string-level post-processing module that handled brace matching, merged multiple \boxed expressions, and separated coordinate-style answers. These changes increased our Kaggle public leaderboard accuracy from 46.9% to 62.5% without requiring additional GPU computation.

We also created a fixed validation and ablation-testing framework to support later self-consistency sampling experiments. During the competition, our team briefly reached first place on the public leaderboard.

Technologies: Python, vLLM, PyTorch, Prompt Engineering, Self-Consistency Sampling, Kaggle
