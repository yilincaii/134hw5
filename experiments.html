MathML: Mass–Energy Equivalence (Extra Credit)

E = m c 2

I think this is a good example of browsers just taking forever to agree on something. MathML has technically been in the spec since the late 90s, but Chrome only added it around version 24, and then removed it again because it was too unstable. Firefox and Safari had their own issues too, so for a long time nothing lined up across browsers.

It wasn’t until Chromium built something called MathML Core (starting around version 109) that Chrome and Edge actually supported it properly. So even though the tag itself is old, I’d guess most browsers only became reliable for MathML sometime around 2023, which is honestly pretty recent for something that’s been in the spec this long.
